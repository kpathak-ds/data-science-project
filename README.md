📊 Customer Behavior Analysis Dashboard

🚀 Project Overview

This project focuses on analyzing customer shopping behavior using data analysis, SQL, and Power BI to extract meaningful insights and support data-driven decision-making.

The goal of this project is to understand customer patterns, purchasing trends, and key factors influencing buying behavior.

⸻

📁 Dataset
	•	Dataset Name: Customer Shopping Behavior
	•	Format: CSV
	•	The dataset contains customer-related information such as purchasing patterns, categories, and behavioral trends.

⸻

🛠️ Tools & Technologies Used

	•	SQL (data querying and analysis)
	•	Power BI (dashboard creation & visualization)
	•	Excel/CSV (data source)

📊 Dashboard Features
